## Current Focus: Domain-Knowledge-Constrained V3 Model

### Problem
V3 model has 22 free parameters, many of which are known from CHO cell biology literature.
Fitting all of them blindly causes instability, correlation issues, and poor CV performance.

### Domain Knowledge Gaps Identified

1. **CHO µ_max (max growth rate)**: Published range 0.8–1.5 d⁻¹. V3 starts at 5.0 — too high.
2. **Yxs (biomass yield on substrate)**: ~2×10⁸ cells/g glucose for CHO. V3 default 200 cells/g — wrong units?
3. **Yps (lactate yield)**: 0.5–0.6 g lactate/g glucose. V3 default 1.3 — too high.
4. **Maintenance m**: 0.05–0.15 g/10⁹ cells/d. V3 default 0.1 g/(cells·d) — wrong units?
5. **Lactate shift trigger**: Scientists know it's triggered by **glucose depletion** (<0.5–1 g/L), not byproduct accumulation. V3 uses `K_iP` (byproduct inhibition) — wrong mechanism.
6. **Feed B composition**: Known from manufacturer specs. Nutrient/substrate ratio should be fixed, not two independent parameters (`C_b`, `C_Nb`).
7. **Cell lysis rate**: Dead CHO cells lyse slowly. k_lys ~0.01–0.05 d⁻¹ is reasonable.

### Recommendation
- Lock 8-10 parameters to literature values
- Fit only unknowns: feed concentrations, inhibition constants, initial conditions
- This reduces 22-param problem to ~12 params → better CV stability
